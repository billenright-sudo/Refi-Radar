# New Home (Overview + Charlie docked) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Home the Overview with a bigger, docked Charlie beside it, with tap-to-talk by default and a Hands-free switch.

**Architecture:** Small pure modules decide layout, talk mode, clip choice and Overview copy (tested with node --test). A new
`CharliePortrait` replaces the circle face. CharliView gains a "dock" mode (replacing its full-page "home" mode) and the
tap-to-talk flow. App renders a `HomeView` = the existing Dashboard body + `CharliView mode="dock"`; "overview" folds into "home".

**Tech Stack:** React 18 + Vite (inline styles), Node 20 `node --test`, Express server untouched.

**Spec:** `docs/superpowers/specs/2026-11-06-new-home-design.md` (approved; its "Builder questions — resolved" section is binding).
